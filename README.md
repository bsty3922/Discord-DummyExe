# Discord DummyExe

DiscordのOrbsクエストなどを達成する際、実際にゲーム本体をダウンロードして起動することなく、Discord側に「対象のゲームを起動している」と認識させるためのツールです。

---

## 🛠 使用方法

1. **ファイル名の変更**  
   ダウンロードした `DiscordDummy.exe` のファイル名を、対象となるゲームの実行ファイル名（任意タイトル）に書き換えます。  
   * **例（NTE「Neverness to Everness」 の場合）:**  
     `DiscordDummy.exe` $\rightarrow$ `HTGame.exe` に変更

2. **実行**  
   名前を書き換えた `.exe` ファイルを実行します。

3. **確認**  
   Discord上で対象のゲームが「プレイ中」として正しく認識されているか確認してください。

---

## ⚠️ 既知の問題点

* **EAタイトル非対応:**  
  EA（Electronic Arts）関連のゲーム（例: *Need for Speed* など）では正常に機能しません。
